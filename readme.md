Qué hace el proyecto? El proyecto inventario lleva a cabo el registro de un producto y su cantidad. Muestra el inventario de los productos, agrega un identificador, su disponibilidad y la fecha en que se registró

Qué tecnologías utiliza? PHP 8.2.12, MariaDB, CSS, XAMPP v3.3.0

Qué se necesita instalar?PHP 8.2.12, un lector de código, navegador web, xampp v3.3.0 

Cómo se configura y ejecuta? Se descomprime el .ZIP, se coloca el proyecto extraído en la carpeta htdocs dentro de XAMPP, se crea la bd usando el sql, se levanta el servicio de XAMPP y se coloca la ruta del proyecto local en el navegador
